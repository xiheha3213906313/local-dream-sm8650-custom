# SM8650 v0.15：输入、比例选择与参考图排序

## 参数卡片与长按调节

- 卡片外部关闭区域与内部空白区域不绘制按压波纹，避免点击时整块界面变黑。
- 关闭正在输入的参数卡片时，先关闭键盘、恢复参数网格并完成布局，再执行卡片缩回动画。
- 长按调节的扩展框下方增加移动刻度，细小滑动也会带动刻度。刻度接近边缘时渐变缩短，边缘保留原高度的一半。
- 锁定比例时长按宽度或高度，另一边保持原尺寸，仅增加联动描边。

## 比例锁

长按锁图标后左右滑动选择 9:16、2:3、3:4、1:1、4:3、3:2、16:9。松手后保持当前选中的比例，尺寸按模型支持的步长对齐。

**锁定期间可以再次长按切换比例，无需先解锁。** 短按锁图标解除联动；重新短按锁定时记录当前比例。

## 提示词与键盘

- 正向提示词标题放入输入框边线上，右下角增加展开图标。输入框在原位置连续扩展，再原位收回；同一个输入实例保留文字、光标和撤销记录。
- 正向提示词获得输入焦点时自动收起负面提示词；键盘关闭后保持收起，手动展开仍可继续编辑原内容。
- 键盘从显示变为隐藏后清除输入焦点，覆盖提示词、数值输入、通用输入框与对话框。

## 图片、结果与模型库

- 参考图短按查看，长按后左右拖动排序。移动到边缘可自动滚动，图片与对应的编码内容整体换位，生成请求使用新顺序。
- 保存、收藏、放大三个主要结果操作等宽，统一为 44dp 高度。
- 采样器、种子、收藏、过滤与 Clip Skip 按钮通过配色与边框显示选中状态，移除文字前附加的勾号。
- 点击分类或左右切换 CPU / NPU / DiT 时，隐藏导入入口并回到列表顶部，不保留上一次滚动位置。CPU 导入入口使用主题强调色，行高保持 52dp。重置只跟随横向分类位移，普通竖向滚动与回弹不触发。

## 安装

原应用 ID 与原证书，versionCode 88，版本 `3.0.0-alpha.8.4-sm8650`，可覆盖 v0.14。
