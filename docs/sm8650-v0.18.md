# SM8650 v0.18：裁剪与生成页面交互

## 修改

- 正向提示词计数沿输入框边线上对齐；后端未设上限时显示 `∞`，不再显示 `0`。图片导入入口上移并与输入框标签留出间距。
- 反转数值参数长按拖动方向：向左增加，向右减小。比例选择顺序保持不变。
- 裁剪页增加常用比例和自由裁剪，显示最终输出尺寸；自由选区匹配当前模型支持的分辨率，再以该比例微调选区。
- 保留原始底图与手动裁剪区域。导入后自动锁定比例，调整分辨率时自动重新裁剪和编码，不再删除底图。自动调整始终以最后一次手动选区为基准，避免来回修改尺寸造成位置漂移。
- 点击底图重新打开裁剪；长按比例锁选择比例后，松手进入裁剪页继续调整。取消裁剪保留原有底图。
- 底图重处理会合并连续尺寸变化，取消旧任务并阻止过期结果覆盖当前尺寸。绘画和蒙版随选区、输出尺寸重新映射，处理完成前暂停底图生成。
- 参数、负面提示词和图片入口增加展开收起过渡。正向提示词使用同一个输入实例平滑移动和缩放，保留光标与编辑状态。裁剪页面增加进出过渡。

## 版本与构建

应用版本 `3.0.0-alpha.8.7-sm8650`，versionCode 91，沿用原包名与签名，可以覆盖 v0.16 和已撤回的 v0.17。

本次仅修改界面及图片准备流程，保留回退后的 v0.16 原生推理引擎与 Qwen 分段加载修复，不包含撤回的 v0.17 性能改动。

按照仓库所有者要求，仅进行代码检查与签名构建，通过后直接发布；不运行测试、截图检查或额外安装包校验，也不回下载发布文件。动画和裁剪交互仍需以手机上的实际体验为准。
