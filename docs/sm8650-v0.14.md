# SM8650 v0.14：宽高联动、筛选控件与键盘过渡

## 模型库

分类恢复为 **CPU / NPU / DiT**。本地列表初次打开时不放入导入行，在顶部下拉后显示。下拉观察器只观察列表没有处理的剩余距离，始终返回零消耗；正常浏览和回滚仍由列表处理。空列表保留导入入口；远程列表不显示本地导入。

## 参数与图片

- 长按参数时，同一个框向上延展，底边保持在原位置，原位置不会空掉。伸长和收回都有 160ms 过渡，名称和数值显示在顶部；左右调整档位时增加轻震动。
- DiT 宽高之间增加锁图标，默认解锁。锁定时记录当前比例，编辑或拖动任一边都会联动另一边，成对约束在 512–2048 范围，并按模型支持的 64 像素步长就近对齐。比例不会因多次调节逐渐漂移；解锁后独立编辑。
- 参数卡片从原位置展开，加快至 200ms，收回为 160ms，保留柔和缓出曲线；移除压暗背景的遮罩颜色，点击外部仍可关闭。
- 底图和参考图缩略图支持点击打开现有缩放查看器，保留缩放、移动和关闭操作。

## 历史与结果

历史页“仅当前模型 / 所有模型 / 过滤”统一为 40dp 高度和相同字号。选中与按下全程使用固定圆角裁切，颜色可以过渡，边缘不会先出现矩形再变圆角。过滤面板中的可点击选项都有底色和边框，选中项增加明确标记，保留模式、收藏、模型、尺寸、采样器、时间、设备、排序与提示词过滤。

结果页删除无效的“导入图片”入口，心形改为文字“收藏”，通过按钮状态与勾选表示已收藏。放大与 UltraFix 的原功能继续使用各自入口。

## 输入法收起时的按钮跳动

此前底部导航在 IME 高度归零时才重新加入布局，生成按钮先跟随键盘到屏幕底部，再因导航占位瞬间向上跳。现在统一使用 `max(键盘高度, 导航区域高度)` 计算底部避让：按钮在键盘动画中到达正常位置后停止，导航在自己的固定位置显现，不再临时改变按钮的最终占位。

## 验证与安装

回归覆盖 360dp 宽度与 1.0 / 1.3 / 1.5 / 2.0 字体，检查下拉导入、尺寸锁及边界、长按伸长中间帧、档位震动、筛选圆角及背景像素、结果收藏、导入图片查看，以及键盘高度逐帧降低时按钮的位置。模拟 IME 高度不能替代小米 14 输入法的实际动画复测。
