# SM8650 v0.6：隔离 VAE 解码与完整数值追踪

## 本次日志证据

v0.5 的 16 组 FP8 矩阵测试（包括大幅值案例）通过；采样模型输出均为有限值。但应用接收图片之前，原生 RGB 已出现绿、蓝通道全零、红通道均值约 0.995 的结果。因此纯色已存在于原生输出中，Android Bitmap 显示不是首要嫌疑。有限的 DiT 输出不等于语义正确，也不能单独证明 VAE 输入正确。

上一版的日志有两处不足：高频 HMX 规划／RPC 回收信息挤掉了开头，末尾 VAE 信息也有缺失；通用 runner 的 VAE 末尾统计未在本次导出中完整出现，无法用它证明裁剪前原始值正常。新版直接在解码、读回与裁剪前后检查，并独立保存。

## 搜索结果

- [上游 #1665](https://github.com/leejet/stable-diffusion.cpp/issues/1665#issuecomment-4725412928)：FLUX.2 Klein 在 Vulkan 输出白图，报告者定位到 `--vae-conv-direct`。
- [上游 #2192](https://github.com/leejet/stable-diffusion.cpp/issues/2192#issuecomment-6352370198)：FLUX.3 Klein 在 Vulkan 出现拼块／色块，报告者将问题进一步定位到 VAE 解码；CPU VAE 可绕过。后续说明小尺寸探测不能覆盖大尺寸错误。

这些是不同模型版本／硬件／后端的案例，不能认定与 SM8650 同因；它们支持优先隔离 VAE 卷积的验证方法。没有找到已确认的同款 v75 修复可直接照搬。调整 CFG 不能替代这一步定位，建议固定 CFG=1、seed=42 做对照。

## 修改

1. **SM8650 改为 CPU VAE，关闭 VAE direct-conv。** DiT 和文本编码器仍在 HTP0；FP8 权重不重下、不转换。固定 512px 验证尺寸使用单帧解码，排除分块合并的干扰。这是针对解码路径的兼容与隔离措施，CPU 解码可能更慢；不是声称已修好 v75 卷积内核。
2. 补齐 `sampler.final_latent`、`vae.denormalized_input`、`vae.decode_input`、`vae.graph_decoded`、`vae.raw_before_clamp`、`vae.after_clamp`、`vae.final_image` 与 RGB 各阶段统计。记录形状、有限值／NaN／Inf、范围、均值、RMS；RGB 形状额外分通道记录。非有限值在裁剪前拒绝，防止裁剪掩盖异常。
3. 关键统计同步写入应用私有的 `sm8650-generation-trace.log`，每次生成重新开始。导出的日志末尾自动附加 `Native generation trace`，不依赖 logcat 是否截断。应用重启后，也能从设置的“查看上次诊断日志”找回最新生成追踪（报告头会标明类型）；文件不自动上传，记录不包含张量原始内容。
4. 减少重复规划与回收日志，保留映射失败和阶段汇总。
5. 适配诊断先保留原有 16 组矩阵检查，再启动独立子进程做 **7 组 HTP 卷积检查**。使用与生产 VAE 一致的权重上传与重排方式，覆盖 RGB、隐藏通道、上采样及 512×512 输出。大尺寸完整执行 DSP 卷积，CPU 参考在边缘、分块边界与内部采样比较，同时检查所有输出的有限性。它能定位某些卷积问题，仍不能证明完整 VAE 正确。

## 手机复测

1. 覆盖安装 v0.6，无需重下模型。仍使用原证书和 v1/v2/v3 签名。
2. 设置 → 运行适配诊断并保存报告。`FP8_DIAG PASS` 对应矩阵部分；`HTP_CONV_DIAG` 是新增卷积部分。即使卷积探测失败，生成也会使用 CPU VAE，不会自动切回有问题的 HTP VAE。
3. 固定 Klein 4B、512×512、4 步、CFG=1、seed=42 生成一张，等待 CPU 解码完成。
4. 返回列表，保存日志。请回传诊断与生成两份日志，特别保留末尾 `Native generation trace`。如果 CPU VAE 后画面恢复，可将问题继续缩小到 HTP VAE；如果仍异常，逐阶段统计能判断是潜变量、解码原始值、裁剪还是像素转换先出错。

## 开发验证

新增 `experimental_trace_test.cpp` 测试有限／非有限值统计、RGB 通道退化、未启用配置时无文件写入、报告重置与并发记录完整性。构建和主机测试通过只能验证代码与诊断机制；本环境没有连接小米 14，CPU VAE 完整出图和 HTP 卷积数值结果仍待手机复测。
