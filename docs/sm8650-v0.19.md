# SM8650 v0.19：输入框、裁剪与参数拖动修复

- 恢复提示词输入框边框。计数容器中的描边明确填满可用尺寸，保留边线计数与 `∞`。
- 正向输入框回到实际布局槽内，参数面板动画与提示词高度、负面标题位置同步变化，去除重复追赶动画。仅主动放大提示词时提升层级，打开参数卡片输入法不会再误触发置顶。
- 裁剪页使用单一选区状态绘制图像、边框和手势；比例切换直接调整当前选区，切回自由模式只解除比例约束，避免组件默认框与恢复框争抢状态导致闪烁。
- 长按分辨率参数或拖动参数卡片滑动条时暂停底图重裁剪；松手后按最终尺寸处理一次，期间保留底图预览并暂停使用未更新的底图生成。
- 参数卡片滑动条在切换数值档位时提供震动反馈。
- 参数与比例长按拖动在实际取值边界截断累计距离；到达末尾后继续向外拖动不再积累，反向拖动立即按正常档位距离切换。

版本 `3.0.0-alpha.8.8-sm8650`，versionCode 92，沿用现有包名、签名和 v0.16 原生推理引擎，不修改生成性能逻辑。
