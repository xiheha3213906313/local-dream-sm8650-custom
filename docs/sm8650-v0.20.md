# SM8650 v0.20：裁剪边界与分辨率确认

- 裁剪图像与手势坐标统一由画布实际尺寸和预览位图尺寸计算；移动、缩放后的选区整体限制在原图范围内，边框和网格也裁切在显示图片区域内。
- 在“自由”左侧增加“完整”。按当前模型支持的分辨率选择最接近原图的比例，并在图片内取该比例能容纳的最大居中选区，尽量减少裁切；输出尺寸仍在裁剪页显示。
- 锁定比例后长按调整宽高，另一侧联动描边以 160 毫秒淡入淡出，保留原参数框尺寸。
- 点按打开宽高卡片后，滑动条和手动输入只修改卡片草稿；点“确定”或键盘确认才应用尺寸并重裁剪底图。点叉、外部或返回关闭时放弃草稿。长按调整参数仍在松手后应用底图裁剪。

版本 `3.0.0-alpha.8.9-sm8650`，versionCode 93，沿用现有包名、签名及 v0.16 原生推理引擎。
